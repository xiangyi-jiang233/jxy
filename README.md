## 更新方式

修改 `index.html`、`notes/` 或 `work-commands/` 中的内容并提交到 `main` 分支，GitHub Actions 会自动重新发布网站。

后续新增或修订的日常工作命令统一维护在 `work-commands/`。工作指令区只记录已验证的命令和必要的非敏感环境路径，不收录密码、密钥、真实 IP、设备编号或内部业务数据。
